Type

Fraunces for headlines. The word “Vigyaan” in the logo is drawn from Fraunces SemiBold and supplied as outlines, so it never needs retyping.

Outfit for everything else.

Please don’t

  • Redraw, recolour, stretch, rotate or crop the mark.
  • Add glow, shadow, gradient or 3-D.
  • Put the bare gold spark on white. Use the tile there.
  • Set the name in capitals, or retype it as the logo.
  • Add ™ or ® to the logo. The logo carries no symbol.
  • Use it for Aura. Aura has its own icon.

A question about using the mark? Write to setu@vigyaan.ai.
